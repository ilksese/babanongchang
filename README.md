# 支付宝芭芭农场脚本

目前实现支付宝和淘宝两类流程。无参数运行或指定 `all` 时，自动检测设备上已安装的应用并执行总工作流。

### 总工作流（默认）

- 同时安装支付宝和淘宝：先执行支付宝，再执行淘宝。
- 只安装支付宝或淘宝：只执行已安装应用的流程。
- 两个都未安装：输出提示并结束，不启动任何应用。
- 每个应用完成后重新检查安装情况，只执行尚未完成的应用；如果先执行淘宝，完成后检测到支付宝，则继续执行支付宝。每个应用最多执行一轮，不循环往返。
- 显式指定 `fertilize`、`goods`、`tasks` 或 `taobao` 时保持单模块运行，不自动串联另一个应用。

支付宝流程会启动支付宝主页 Activity，通过 OCR 判断当前页面。在首页识别并等待“芭芭农场”入口稳定后，只点击一次并确认进入农场。首页既支持底部“首页”配合顶部功能入口的识别方式，也支持顶部“扫一扫”“收付款”等功能与底部“理财”“消息”“我的”等导航的组合，不强制依赖“首页”文案。未知页面只等待识别，超时后停止，不盲目发送返回键，以免退出到桌面；需要时请手动切换到支付宝首页。未登录、首页未展示农场入口或页面加载超时时会安全停止，不猜测坐标。已在农场或任务弹窗时会识别当前页面后继续。

支付宝内部按以下顺序执行一轮：

1. 执行任务池中所有可执行的“做任务领肥料”任务并领取奖励。
2. 根据 OCR 任务标题定位弹窗上方遮罩，点击一次关闭任务弹窗，再确认农场首页稳定出现。不使用系统返回键关闭弹窗，避免关闭小程序；找不到安全遮罩或点击后未关闭时停止。
3. 执行一次“逛农货/百县百品”，返回农场首页。
4. 施肥至余额不大于阈值（默认 600），或达到 `--max-clicks` 限制。

任一步识别失败或超时都会安全停止，不继续后续阶段或切换应用。`--browse-seconds` 用于支付宝流程的浏览时长，`--threshold` 和 `--max-clicks` 仅控制支付宝的施肥阶段；淘宝沿用自身任务配置。

### 淘宝流程

当前已接入启动淘宝，从首页进入芭芭农场，打开“集肥料”任务列表，并按页面顺序执行已支持的搜索、好物浏览和视频浏览任务：

启动流程会直接打开淘宝主页 Activity `com.taobao.taobao/com.taobao.tao.welcome.Welcome`，再根据 OCR 页面状态逐步进入芭芭农场任务列表；即使设备最初停留在其他应用或淘宝未知页面，也不依赖原有页面栈。

进入农场后会等待页面和“集肥料”入口连续三帧稳定，再执行一次点击。点击期间不会重复触发；如果跳转后未进入任务列表，会返回农场首页、重新等待页面稳定后重试。

浏览结束后会逐次执行返回并识别当前页面，直到确认回到肥料任务列表；超时仍未返回时会安全停止。

每次返回任务列表后都会重新扫描全部已接入任务，而不是将任务分阶段清空。当前接入“去签到”“搜一搜你喜欢的商品”“搜一搜你心仪的宝贝”“发现精选好物”“逛精选好物”和“看严选推荐商品”，并按任务在屏幕中从上到下的自然顺序执行。“去签到”直接点击一次，等待按钮消失且仍在任务列表后重新扫描，不执行浏览或返回操作；等待超时则停止，避免重复点击。搜索任务进入结果列表往复滑动 18 秒，“发现精选好物”和“逛精选好物”进入商品流往复滑动 18 秒，严选推荐商品进入视频页面静止停留 18 秒。只有某一轮扫描中全部已接入任务都没有可执行按钮时，才结束脚本。

```bash
uv run babanongchang taobao --serial <ADB_SERIAL>
```

### 挪了个箭

先手动进入“挪了个箭”，保持游戏在已解锁、授权 ADB 的 Android 设备前台，再运行：

```bash
uv run babanongchang games --nlgj
# 识别当前设备画面，不点击
uv run babanongchang games --nlgj --dry-run
# 快速模式：按分析出的顺序每 300ms 点击一条箭头
uv run babanongchang games --nlgj --mode fast --serial <ADB_SERIAL>
# 完全离线识别截图，不连接设备
uv run babanongchang games --nlgj --screenshot image.png --ocr
```

实现迁自 `nuolegejian`，已包含在本项目中。默认使用 `safe` 模式，每次确认箭头离场及剩余棋盘后再继续，最多通关 3 次或运行 15 分钟。`--levels 0 --max-minutes 30` 可只按时间运行；`--target 100` 表示完成第 100 关或更高关卡后停止，覆盖通关次数和总时间限制。全部参数见 `uv run babanongchang games --nlgj --help`。

失败时默认优先观看复活广告，确认固定 30 秒广告页后上下滑动 33 秒，再识别“奖励已发放”并关闭广告。默认不消耗体力重开；恢复连胜仅使用已确认足够的现有金币，余额不足则放弃，`--streak-policy stop` 可禁止此操作。遇到爱心减少、前台应用切换、未知弹窗或无法确认的棋盘时停止；按 `Ctrl+C` 可手动停止。

适配白底深色直角折线箭头棋盘，特殊机关、严重重叠或裁切可能被拒绝操作。诊断截图、标注和日志默认写入已忽略的 `artifacts/nlgj/`，可通过 `--output` 修改。

### 麻将游戏

先手动进入当前麻将关卡，再运行：

```bash
uv run babanongchang games --majiang
```

- 底部同时识别到“消除、洗牌、翻牌、磁铁”后开始，读取磁铁数量和剩余牌数。
- 磁铁为 0 时打开磁铁弹窗，只点“免费”看广告，不花金币购买。
- 广告页上下滑动 30 秒，再每隔 1 秒识别“已获得奖励”；未领奖且仍显示倒计时时继续往复滑动，避免倒计时停滞。最多额外等待 120 秒，超时保留页面并停止。
- 领奖后只点广告右上角“关闭”，绝不使用系统返回键；点击奖励弹窗“确定”，确认磁铁到账后使用。
- 每次点击后等待牌数减少且页面稳定，通关后自动点击“下一关”，确认新关卡稳定后继续。按 `Ctrl+C` 手动停止；数量无法识别、遇到未知弹窗或步骤超时时自动停止，不重试超时步骤。
- 仅以“关卡完成”等通关弹窗文案判定通关；剩余牌数为 0 时仍等待通关弹窗，超时则停止，不继续领取磁铁或点击下一关。
- 进入下一关后额外比较牌面图像，连续多帧静止才开始点击磁铁，避免洗牌动画屏蔽点击。洗牌等待最多 40 秒，超时停止；不因按钮提前显示就开始操作。
- 长时间闲置自动出现的道具推荐弹窗只关闭、不使用；定位弹窗自身的白色关闭圆环，点击一次并确认弹窗消失后继续。
- 出现“时间到了”时，仅点击左侧免费广告“加时”；看完广告点击右上角“关闭”，确认回到游戏再继续。不花金币加时，免费按钮不可用时停止。
- 可从本流程的奖励广告页面恢复启动；此时仍完整滑动 30 秒再检查奖励。

### 施肥

- 从手机截图识别 `肥料 + 数字`，余额大于 600 时点击“施肥”。
- 出现“立即领肥”时，依次点击“立即领肥”“立即领取”；有“逛一逛”时继续点击。
- 在“浏览或查看商品领肥料”页面上下往复滑动 18 秒，随后返回继续施肥。
- 当天浏览奖励已完成、领取后直接返回施肥页时，跳过本轮浏览并继续。
- 余额不大于 600 或识别失败时安全停止。

### 逛农货 / 百县百品

- 从首页左上方识别“逛农货”或“百县百品”入口，避开页面中间的同名横幅。
- 进入二级页面后持续上下往复滑动 18 秒（任务要求 15 秒，额外预留 3 秒）。
- 返回并确认芭芭农场首页；每次运行只执行一轮。

### 做任务领肥料

- 从首页右下方进入“领肥料”，等待“做任务领肥料”弹窗动画结束。
- 滑动任务列表，处理“逛好物”浏览任务和“看精选商品得肥料”。
- 对有“去完成”按钮的任务浏览 18 秒，返回后领取奖励并等待任务刷新。
- 重复执行当天可用次数，直到任务池中的浏览任务均无可执行按钮。

任务规则统一注册在 `src/babanongchang/task_pool.py`：

- `TaskMatcher(fixed_text=...)` 匹配固定文案。
- `TaskMatcher(pattern=...)` 使用正则表达式匹配动态文案。
- `TaskDefinition` 配置任务名称、操作类型、按钮文案和执行时长。
- 当前支持 `SWIPE_BROWSE`（上下滑动浏览）操作，默认时长为 18 秒，每个任务可单独覆盖。
- 浏览页面出现阿拉伯数字形式的“第 n 次”时，本轮时长按任务配置时长乘以 `n` 计算；例如默认配置下“第3次”浏览 54 秒。

通用上下滑动功能位于 `src/babanongchang/browsing.py`。任务执行策略位于 `src/babanongchang/task_executors.py`，目前提供：

- `SwipeBrowseExecutor`：进入页面后按配置时长滑动浏览。
- `ClickAndReturnExecutor`：进入页面并等待跳转完成，随后由公共流程立即返回任务列表。

点击返回型任务默认 `stay_seconds=0`：点击“去完成”后只要检测到任务列表已消失便立即返回，不等待目标页面稳定，以免期间出现其他弹窗；大于 0 时才继续等待目标页面并停留指定时间。返回操作必须确认任务弹窗和列表已恢复稳定，随后手动点击“领取”。目前已接入：

- 逛支付宝得金豆
- 逛支付宝金豆得宝
- 逛一逛蚂蚁庄园
- 逛一逛森林组队种
- 逛一逛支付宝会员
- 逛一逛金豆乐园
- `玩一玩…`（前缀匹配，停留 600 秒）

后续接入其他操作时，在任务池增加操作类型和规则，并在 `TASK_EXECUTORS` 注册对应执行策略。

## Android APK

APK 已接入全部 CLI 业务入口：支付宝连续施肥、逛农货、任务池、淘宝完整流程、麻将及挪了个箭。手机端直接复用 Python 自动化逻辑，通过无障碍服务完成本机操作，无需连接电脑或 ADB。

应用中选择功能并填写 CLI 附加参数；支持日志、挪了个箭离线截图识别和诊断导出。构建、使用及真机验收限制见 [Android 说明](android/README.md)。

## 环境

- Python 3.14（当前使用 3.14.6）
- 已加入 `PATH` 的 ADB
- 已连接并授权的 Android 设备

## 使用

连接、授权并解锁设备，确保已登录安装的支付宝或淘宝，然后运行总工作流（自动启动应用，不需要手动进入农场）：

```powershell
chcp 65001 | Out-Null
uv sync
uv run babanongchang
```

也可以显式运行总工作流，或只执行施肥：

```powershell
uv run babanongchang all
uv run babanongchang fertilize
```

执行每日一次的“逛农货/百县百品”：

```powershell
uv run babanongchang goods
```

执行“做任务领肥料”：

```powershell
uv run babanongchang tasks
```

可以从芭芭农场首页启动，也可以在“做任务集肥料”任务列表已经打开时直接启动。

先限制为一次点击进行验证：

```powershell
uv run babanongchang fertilize --max-clicks 1
```

可用参数：

```text
--serial SERIAL          指定 ADB 设备
--threshold 600          停止施肥的余额阈值
--browse-seconds 18      浏览奖励页面的滑动时长（不能少于 15 秒）
--max-clicks N           限制本次施肥点击次数
```

运行期间可按 `Ctrl+C` 停止。脚本只在同时识别到余额和“施肥”按钮后点击；关键页面识别超时会停止，不会猜测坐标继续操作。

脚本启动时会主动唤醒设备，并在运行期间通过 ADB 强制保持亮屏；退出时会恢复系统自动休眠。运行前仍需手动解锁手机。总工作流会自动进入农场；单独执行 `fertilize`、`goods` 或 `tasks` 时，仍需先打开对应的支付宝芭芭农场页面。

公共 OCR 文案操作位于 `src/babanongchang/handle.py` 的 `TextHandle`，`FarmAutomation` 通过继承复用：

- `scan()`：截取当前屏幕并执行 OCR，返回包含图片和文字项的 `ScreenSnapshot`。
- `find_text()` / `find_texts()` / `has_text()`：查找单项、全部匹配项或判断文案是否存在，支持精确匹配和相对屏幕区域过滤。
- `find_same_row_text()`：根据标题与按钮的同行布局关系定位操作按钮。
- `wait_for_screen()`：按项目配置的截图间隔轮询业务页面判定函数。
- `wait_for_stable_screen()` / `wait_for_stable_text()`：等待页面、页面签名或文字坐标连续多帧稳定。
- `wait_for_text(text="", timeout=10000)`：等待文案出现，返回文字中心坐标；也可传入文案序列，只有同一屏同时出现全部文案时才按传入顺序返回坐标列表；超时单位为毫秒。
- `wait_for_all_text()` / `wait_for_any_text()` / `wait_for_text_gone()`：分别等待全部文案、任一文案或文案消失。
- `click_text(text="", wait=True, timeout=10000)`：等待并点击文案，返回点击坐标；`wait=False` 时只识别当前屏幕一次。
- `tap_and_wait()` / `click_text_and_wait()`：只点击一次并等待目标页面，等待期间不会重复点击。

通用返回操作位于 `src/babanongchang/navigation.py`：`back_until()` 每次返回后重新识别页面，直到目标页面出现或超时。

项目级配置位于根目录 `babanongchang.toml`，在进程启动时读取：

```toml
[ocr]
screenshot_interval_ms = 200
recognition_timeout_ms = 10000
```

- `screenshot_interval_ms`：等待 OCR 文案时连续截图的间隔，默认 200 毫秒。
- `recognition_timeout_ms`：OCR 文案等待的默认超时，默认 10 秒。

扫描任务列表时会逐屏输出命中的任务、操作类型和按钮状态，例如：

```text
任务识别（当前屏幕）：
  - 逛一逛支付宝会员 (0/1) -> click_and_return [去逛逛]
```
