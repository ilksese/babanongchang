# 支付宝芭芭农场脚本

目前实现四个模块。

### 淘宝流程

当前已接入启动淘宝，从首页进入芭芭农场，打开“集肥料”任务列表，并按页面顺序执行已支持的搜索、好物浏览和视频浏览任务：

启动流程会直接打开淘宝主页 Activity `com.taobao.taobao/com.taobao.tao.welcome.Welcome`，再根据 OCR 页面状态逐步进入芭芭农场任务列表；即使设备最初停留在其他应用或淘宝未知页面，也不依赖原有页面栈。

进入农场后会等待页面和“集肥料”入口连续三帧稳定，再执行一次点击。点击期间不会重复触发；如果跳转后未进入任务列表，会返回农场首页、重新等待页面稳定后重试。

浏览结束后会逐次执行返回并识别当前页面，直到确认回到肥料任务列表；超时仍未返回时会安全停止。

每次返回任务列表后都会重新扫描全部已接入任务，而不是将任务分阶段清空。当前接入“去签到”“搜一搜你喜欢的商品”“搜一搜你心仪的宝贝”“发现精选好物”和“看严选推荐商品”，并按任务在屏幕中从上到下的自然顺序执行。“去签到”直接点击一次，等待按钮消失且仍在任务列表后重新扫描，不执行浏览或返回操作；等待超时则停止，避免重复点击。搜索任务进入结果列表往复滑动 18 秒，“发现精选好物”进入商品流往复滑动 18 秒，严选推荐商品进入视频页面静止停留 18 秒。只有某一轮扫描中全部已接入任务都没有可执行按钮时，才结束脚本。

```bash
uv run babanongchang taobao --serial <ADB_SERIAL>
```

### 施肥

- 从手机截图识别 `肥料 + 数字`，余额大于 600 时点击“施肥”。
- 出现“立即领肥”时，依次点击“立即领肥”“立即领取”；有“逛一逛”时继续点击。
- 在“浏览或查看商品领肥料”页面上下往复滑动 18 秒，随后返回继续施肥。
- 当天浏览奖励已完成、领取后直接返回施肥页时，跳过本轮浏览并继续。
- 余额不大于 600 或识别失败时安全停止。

### 逛农货 / 百县百品

- 从首页左上方识别“逛农货”或“百县百品”入口，避开页面中间的同名横幅。
- 进入二级页面后持续上下往复滑动 18 秒（任务要求 15 秒，额外预留 3 秒）。
- 返回并确认芭芭农场首页；每次运行只执行一轮。

### 做任务领肥料

- 从首页右下方进入“领肥料”，等待“做任务领肥料”弹窗动画结束。
- 滑动任务列表，处理“逛好物”浏览任务和“看精选商品得肥料”。
- 对有“去完成”按钮的任务浏览 18 秒，返回后领取奖励并等待任务刷新。
- 重复执行当天可用次数，直到任务池中的浏览任务均无可执行按钮。

任务规则统一注册在 `src/babanongchang/task_pool.py`：

- `TaskMatcher(fixed_text=...)` 匹配固定文案。
- `TaskMatcher(pattern=...)` 使用正则表达式匹配动态文案。
- `TaskDefinition` 配置任务名称、操作类型、按钮文案和执行时长。
- 当前支持 `SWIPE_BROWSE`（上下滑动浏览）操作，默认时长为 18 秒，每个任务可单独覆盖。
- 浏览页面出现阿拉伯数字形式的“第 n 次”时，本轮时长按任务配置时长乘以 `n` 计算；例如默认配置下“第3次”浏览 54 秒。

通用上下滑动功能位于 `src/babanongchang/browsing.py`。任务执行策略位于 `src/babanongchang/task_executors.py`，目前提供：

- `SwipeBrowseExecutor`：进入页面后按配置时长滑动浏览。
- `ClickAndReturnExecutor`：进入页面并等待跳转完成，随后由公共流程立即返回任务列表。

点击返回型任务默认 `stay_seconds=0`：点击“去完成”后只要检测到任务列表已消失便立即返回，不等待目标页面稳定，以免期间出现其他弹窗；大于 0 时才继续等待目标页面并停留指定时间。返回操作必须确认任务弹窗和列表已恢复稳定，随后手动点击“领取”。目前已接入：

- 逛支付宝得金豆
- 逛支付宝金豆得宝
- 逛一逛蚂蚁庄园
- 逛一逛森林组队种
- 逛一逛支付宝会员
- 逛一逛金豆乐园
- `玩一玩…`（前缀匹配，停留 600 秒）

后续接入其他操作时，在任务池增加操作类型和规则，并在 `TASK_EXECUTORS` 注册对应执行策略。

## 环境

- Python 3.14（当前使用 3.14.6）
- 已加入 `PATH` 的 ADB
- 已连接并授权的 Android 设备

## 使用

保持支付宝芭芭农场施肥页面位于前台，然后运行：

```powershell
chcp 65001 | Out-Null
uv sync
uv run babanongchang
```

执行每日一次的“逛农货/百县百品”：

```powershell
uv run babanongchang goods
```

执行“做任务领肥料”：

```powershell
uv run babanongchang tasks
```

可以从芭芭农场首页启动，也可以在“做任务集肥料”任务列表已经打开时直接启动。

先限制为一次点击进行验证：

```powershell
uv run babanongchang fertilize --max-clicks 1
```

可用参数：

```text
--serial SERIAL          指定 ADB 设备
--threshold 600          停止施肥的余额阈值
--browse-seconds 18      浏览奖励页面的滑动时长（不能少于 15 秒）
--max-clicks N           限制本次施肥点击次数
```

运行期间可按 `Ctrl+C` 停止。脚本只在同时识别到余额和“施肥”按钮后点击；关键页面识别超时会停止，不会猜测坐标继续操作。

脚本启动时会主动唤醒设备，并在运行期间通过 ADB 强制保持亮屏；退出时会恢复系统自动休眠。运行前仍需手动解锁手机并打开对应的芭芭农场页面。

公共 OCR 文案操作位于 `src/babanongchang/handle.py` 的 `TextHandle`，`FarmAutomation` 通过继承复用：

- `scan()`：截取当前屏幕并执行 OCR，返回包含图片和文字项的 `ScreenSnapshot`。
- `find_text()` / `find_texts()` / `has_text()`：查找单项、全部匹配项或判断文案是否存在，支持精确匹配和相对屏幕区域过滤。
- `find_same_row_text()`：根据标题与按钮的同行布局关系定位操作按钮。
- `wait_for_screen()`：按项目配置的截图间隔轮询业务页面判定函数。
- `wait_for_stable_screen()` / `wait_for_stable_text()`：等待页面、页面签名或文字坐标连续多帧稳定。
- `wait_for_text(text="", timeout=10000)`：等待文案出现，返回文字中心坐标；也可传入文案序列，只有同一屏同时出现全部文案时才按传入顺序返回坐标列表；超时单位为毫秒。
- `wait_for_all_text()` / `wait_for_any_text()` / `wait_for_text_gone()`：分别等待全部文案、任一文案或文案消失。
- `click_text(text="", wait=True, timeout=10000)`：等待并点击文案，返回点击坐标；`wait=False` 时只识别当前屏幕一次。
- `tap_and_wait()` / `click_text_and_wait()`：只点击一次并等待目标页面，等待期间不会重复点击。

通用返回操作位于 `src/babanongchang/navigation.py`：`back_until()` 每次返回后重新识别页面，直到目标页面出现或超时。

项目级配置位于根目录 `babanongchang.toml`，在进程启动时读取：

```toml
[ocr]
screenshot_interval_ms = 200
recognition_timeout_ms = 10000
```

- `screenshot_interval_ms`：等待 OCR 文案时连续截图的间隔，默认 200 毫秒。
- `recognition_timeout_ms`：OCR 文案等待的默认超时，默认 10 秒。

扫描任务列表时会逐屏输出命中的任务、操作类型和按钮状态，例如：

```text
任务识别（当前屏幕）：
  - 逛一逛支付宝会员 (0/1) -> click_and_return [去逛逛]
```
