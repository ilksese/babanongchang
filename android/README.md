# Android 单次施肥验证版

**非正式可用版，尚未通过指定实体手机验收。** 当前仅有 Android 13 / API 33 模拟器上的本地模拟页面证据，不是实际支付宝或实体手机证据，也不等于三次真实施肥闭环。实体音量键接收与拦截尚未可靠证明，应停留在受控验证阶段，不建议进行真实施肥。任务 05 的设备验收尚不能关闭。

## 构建与产物

- 使用 Java 17、Android SDK 36 和仓库自带 Gradle Wrapper（Gradle 9.1.0）；先配置本机 JDK 与 Android SDK 路径。首次构建需要下载依赖。
- 在本目录执行 debug 单元测试与构建（无需连接设备，不执行 release / 生产构建）：

  ```sh
  ./gradlew testDebugUnitTest assembleDebug
  ```

- debug APK 位于本目录的 `app/build/outputs/apk/debug/app-debug.apk`，仅供自用侧载验证；构建成功不代表设备验收通过。
- 工程声明 `minSdk = 30`（Android 11）、`compileSdk / targetSdk = 36`。最低版本只是声明，不保证 Android 11+、所有厂商系统或指定手机兼容；截图、OCR、按键及浮层仍需逐台验证。
- 原有 Python 版本保留可用，使用方式见仓库根目录 README；本 APK 不嵌入 Python，运行时不依赖电脑或服务器。

## 授权与准备

以下仅说明验证流程，不代表授权安装、修改设置或真实施肥；读取设备信息、安装 APK、授予权限与真实施肥须分别获得明确许可。关键音量键和控制能力验证可靠前，不推进真实施肥。

1. 侧载 debug APK 后打开应用，阅读权限与风险说明。通过“打开系统无障碍设置”进入系统设置，由用户手动授权本应用无障碍服务；如系统限制侧载应用授权，按系统提示自行决定，不绕过限制。
2. 无障碍服务用于本地截图、OCR、单次手势、音量键过滤及控制浮层，不要求 Root、无线调试、Shizuku 或通用悬浮窗权限。授权成功本身不证明系统支持所有能力。
3. 用户自行登录支付宝，解锁并保持亮屏，手动进入芭芭农场。运行及暂停期间都不要手动改变农场状态、切换应用或同时操作页面，否则余额变化无法可靠归因。
4. 能力不支持、音量键无效或浮层不可用时停止验证，在系统设置中关闭服务并报告具体阻碍，不自行改用额外权限或其他控制路线。无需验证时也可手动关闭服务。

## 单轮行为与控制约定

下列是实现约定，**不表示按键与暂停继续已通过平台或真机验收**。浮层“开始单次施肥验证”会隐藏浮层，并可能发出消耗真实肥料的手势；当前不建议在实际农场点击此按钮。

- 每次手动开始只运行一轮，先识别支付宝农场、肥料余额和施肥按钮；余额严格大于 **600** 才允许一次施肥尝试，余额不大于 600 则报告“未执行”，不点击。
- 点击前识别、点击后确认各最多 **10 秒活跃时间**，提前满足条件即可结束，不是固定等待 10 秒。阈值与时限固定，不提供配置。
- 一轮最多一次点击；仅在有效农场页面确认肥料余额比点击前减少，才报告“施肥成功”。手势发送或回调完成都不等于成功。
- 已发起尝试但无法确认余额减少时报告“结果未确认”，绝不自动补点。**结果未确认不等于施肥未发生**，不要据此重复尝试。
- 运行中音量上暂停、音量下结束，并恢复浮层；暂停时音量上保持暂停，音量下结束。继续只能点击浮层“继续”，也可点击“结束”。运行及暂停时按键应不调音量，未开始或已结束时应恢复正常音量功能；长按、重复事件不应继续或开始新一轮。这些平台行为仍待验收。
- 暂停不发起新截图、OCR 或设备操作，暂停时间不消耗等待额度。点击前继续会重新识别页面与位置；点击后继续只确认原尝试，不再次点击。**已发送的手势无法保证撤销**，暂停或结束不是撤销施肥。
- 结束丢弃本轮进度但不退出 APK；点击后尚未确认就结束，应显示“已结束，施肥结果未确认”。新一轮必须再次手动开始。
- 弹窗、应用切换、锁屏、权限失效或页面无法确认时安全停止，不关闭弹窗、不领取奖励、不返回、不自动恢复；干扰与余额减少同时出现时优先安全停止。完成或停止后恢复浮层展示结果。

## 数据与范围

截图、中文 OCR 与必要文字结果均在本地处理，不上传；中文模型随 APK 打包，无网络权限。默认截图只驻留内存、用完释放，不留存截图或 OCR 全文，不保存历史日志，仅保留当前进程最近一轮必要结果。

Android 验证版不自动登录、解锁、启动或导航进入农场，不自动领奖、关闭弹窗、返回或循环施肥，不覆盖任务池、淘宝、麻将、广告、定时或无人值守流程。不承诺商店发布、多机型兼容、长期稳定性，也不能保证不触发目标平台风控。

**仍未验收：** 实体音量键可靠接收/拦截及音量恢复、平台暂停/继续/结束闭环、长按与重复事件、指定手机截图/OCR/手势与浮层兼容性，以及三次手动独立启动的真实施肥。ADB 注入按键或媒体音量未变化均不能证明实体按键可靠；模拟页面的一次余额减少不能当作三次真实闭环。
