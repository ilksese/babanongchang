# Triage labels

技能提到以下角色时，使用对应的 GitHub 标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待报告者补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可交给 Agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予实施 |

需要调整标签命名时，修改此表的 GitHub 标签列。
